# object_detection
object detection app using yolo5
A real-time object detection application using YOLOv4 and OpenCV, with speech output for detected objects.


Features

Real-time object detection using YOLOv4
Speech output for detected objects
Bounding box visualization



Requirements

Python 3.x
OpenCV
NumPy
PyQt5
pyttsx3



Installation

Clone the repository
Install required packages: pip install opencv-python numpy pyqt5 pyttsx3
Download YOLOv4 model weights and configuration files



Usage

Run the application: python object_detection_app.py
Click "Start" to begin object detection
Click "Stop" to stop object detection



Notes

Make sure to update the MODEL_PATH, CONFIG_PATH, and CLASS_PATH constants with the correct file paths.
This application uses the COCO dataset classes.
